throughline skills for Claude Code

A plugin marketplace for working in throughline IDD requirements repositories. Install once and it applies in your own repos. Your graph is committed there, as it must be — throughline is git-native and the items are the product. It is the skill that stays out: no copy of it is vendored into your repo, and nothing is installed on your laptop.

Install

In Claude Code, in the terminal or at claude.ai/code:

/plugin marketplace add https://skills.iddn.uk/marketplace.json
/plugin install tl@throughline-skills

If github.com is reachable, adding the repository directly does the same thing: /plugin marketplace add rhodium-org/throughline-skills. In the browser you can also use Manage plugins → Marketplaces → Add marketplace and paste either source.

What's in it

/tl:multigraph
Repositories holding more than one throughline graph, composed with tl-compose: picking the right binary per graph, wiring sibling graphs by path, gating them all, and ratifying items whose grounding chain crosses graphs.
/tl:challenge
A challenge pass before hand-off: the twelve questions tl check cannot ask, with a script for the deterministic ones. Also re-checks an implementation graph against a specification it composes once that specification moved: stamped links, suspect-link triage, and spec items nothing implements.

Each skill activates on its own when Claude notices the situation it covers, or you can invoke one as /tl:multigraph or /tl:challenge.

On a locked-down laptop

This is designed for it. Everything runs in the Claude sandbox: the skill installs the CLI it needs itself with pip install throughline-compose, which needs Python 3.11 or later — cloud sessions have it. Graphs wired to each other by path need no network at all. Graphs adopting an external standard by url need the sandbox to reach that host, so use https:// URLs and never an SSH host alias, which will not resolve there.

Updating

Bump-driven, not automatic: /plugin marketplace update throughline-skills.
